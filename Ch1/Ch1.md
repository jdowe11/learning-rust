## Cargo Build

Learned how to create cargo package builds
```bash
cargo new <project> # creates a new cargo project
cargo build # compiles project
cargo run # compiles and runs project
cargo check # checks if the program can be compiled into executable
cargo build --release # compiles and optimizes code for speed
```
